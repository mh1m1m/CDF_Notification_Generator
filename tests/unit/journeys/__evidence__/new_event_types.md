## 5. Contract additions (ACCEPTED by L-05 item 4; W-A adds them)

- `CaseRecord.history` (optional): `[{code, recorded_at, source_event_id}]` — the recorded V8 positions in order. With it, Level 1 marks earlier stages COMPLETED as RECORDED_FACT; without it the resolver derives only the stages every path to the current code must pass (DERIVED_FROM_VERIFIED_FACTS) and marks the rest UNVERIFIED.
- `ProceduralObject.related_objects` (optional): `[{type, id}]` — objects whose events belong to this procedure (for example the meeting and ballot of a recommendation, or the grievance proceeding of a decision). Events on any other object are ignored with reason OBJECT_MISMATCH.
- `NOTIFICATION_SENT.payload.subject_object_id`: the procedural object a sent notice is about (mirrors the subject object of `notify.enqueue`). A step that consists of notifying someone completes only on such an event, never on the notice being rendered.

## 6. Open items for W-A and W-D1 (INFERENCE unless marked)

- Single-type consumers: a step with `completion_any_of` keeps `completion_event_type` = the first pattern. A checker that compares evidence with `completion_event_type` only (W-A INV-11 through a catalogue projection) must also read `completion_any_of`; the resolver progress rows already report the type of the matched evidence, so W-D1 PC-09 is satisfied. **DECISION (L-10):** W-A's INV-11 also reads `completion_any_of`.
- `PROCEDURE_COMPLETED` targets: the 11 closure steps include those of the task, recommendation, decision-notice and implementation journeys, whose objects are probably TASK, RECOMMENDATION, DECISION and IMPLEMENTATION_ACTION (INFERENCE: the catalogue records no object type per journey). W-A lists PROCEDURE and INVESTIGATION as the object types of `PROCEDURE_COMPLETED` (FACT, `src/domain/concepts.js`). **DECISION (L-10):** W-A accepts the catalogue's closure targets through `payload.target`.
- `REFERRAL_RETURNED`: W-A cites both platform RETURNED_FOR_COMPLETION and SECTOR_RETURNED as its source (FACT, `src/domain/concepts.js`). If SECTOR_RETURNED were recorded as `REFERRAL_RETURNED`, J-DR-SECRETARY 2/3 would show a return that did not happen. **DECISION (L-10):** `REFERRAL_RETURNED` is platform RETURNED_FOR_COMPLETION only (the secretary's return for completion); platform SECTOR_RETURNED is `REFERRAL_HEAD_DECIDED` with `{decision: RETURNED}`, because one platform fact maps to one V13 type. W-A corrects its source citation and PLATFORM_AUDIT_EVENT_MAP; the catalogue already reads the types this way.
- `REFERRAL_RESUBMITTED` (a W-A type) and the adopted `REFERRAL_SUBMITTED` with `resubmission: true` (L-05 item 2) recorded the same fact. **DECISION (L-10):** the recorded form is `REFERRAL_SUBMITTED` with `{resubmission: true}`, and W-A retires `REFERRAL_RESUBMITTED`; W-A's status.js keeps the transition RETURNED or FAILED → IN_PROGRESS on `REFERRAL_SUBMITTED`. The catalogue already reads the payload flag, so it does not change.
- `NOTIFICATION_SENT.payload.purpose` is not emitted by the W-D1 lifecycle today (FACT, `src/lifecycle/notification.js` sentRefs); reminder steps therefore also accept the template code. Three reminder purposes (TASK_REMINDER, CONFIDENTIALITY_REMINDER, MEETING_REMINDER) have no platform template code (FACT, packages/contracts NOTIFICATION_TEMPLATES). **BACKLOG (L-10):** both are left for later and not built now.
- The 58 adopted types (section 3). **DECISION (L-10, L-05 item 2):** W-A adds them to `EVENT_TYPES`. JR-05 prints how many are present and does not fail on the count.
- `BALLOT_CLOSED` with result NO_DECISION: by default the platform records it when a quorate ballot has no APPROVE and no REJECT vote (FACT, packages/contracts `VOTE_RESULTS`, packages/domain `voteOutcome`), and W-A lists it (FACT, `src/domain/concepts.js`). Before L-11 the catalogue did not read it, so J-MEETING 3/4 stayed a possible step after such a closure, even after the meeting closed. **DECISION (L-11):** NO_DECISION is a recorded ballot outcome, not a failure. Applied: `J-MEETING/3/4` lists NO_DECISION among its completion results; 3/3 and 2/2 already completed on any closure other than NO_QUORUM (test JR-24).
